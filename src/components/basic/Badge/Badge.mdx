# Badge

A small count or status label. Supports 8 variants, sizes, and gradient/pulse effects.

## Usage

```tsx
import { Badge } from 'morphui-react';

<Badge variant="primary" size="sm">New</Badge>
<Badge variant="danger" pulse>3</Badge>
```

## Accessibility

Renders a `<span>` with no implicit role. For status indicators, set `aria-label`. The `pulse` animation respects `prefers-reduced-motion`.
