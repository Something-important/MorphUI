# Breadcrumb

Navigation trail showing the user's location in the app hierarchy. Accepts an `items` array and renders an `<nav>` with `<ol>`.

## Usage

```tsx
import { Breadcrumb } from 'morphui-react';

<Breadcrumb
  items={[
    { label: 'Home', href: '/' },
    { label: 'Settings', href: '/settings' },
    { label: 'Profile' },
  ]}
/>;
```

## Accessibility

`<nav>` with `aria-label="Breadcrumb"`. Each item is an `<a>` or `<span>` (current page). The last item has `aria-current="page"`.
