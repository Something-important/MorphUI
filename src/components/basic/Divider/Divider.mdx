# Divider

A horizontal or vertical separator line with variant and gradient support.

## Usage

```tsx
import { Divider } from 'morphui-react';

<Divider variant="default" />
<Divider orientation="vertical" />
```

## Accessibility

Renders `<hr>` for horizontal (semantic separator) or `<div>` with `role="separator"` for vertical. `aria-orientation` is set appropriately.
