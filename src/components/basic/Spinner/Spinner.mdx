# Spinner

An animated loading spinner with size, color, and label support.

## Usage

```tsx
import { Spinner } from 'morphui-react';

<Spinner size="md" />
<Spinner label="Loading data..." />
```

## Accessibility

`role="status"` with `aria-live="polite"`. The `label` prop sets `aria-label`. Animation respects `prefers-reduced-motion`.
