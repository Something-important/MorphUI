# ContextMenu

A right-click context menu with controlled open state, viewport clamping, and keyboard navigation.

## Usage

```tsx
import { ContextMenu } from 'morphui-react';

<ContextMenu items={[
  { label: 'Copy', onClick: copy },
  { label: 'Paste', onClick: paste },
  { type: 'separator' },
  { label: 'Delete', onClick: del, disabled: true },
]}>
  <div onContextMenu={...}>Right-click me</div>
</ContextMenu>
```

## Accessibility

`role="menu"` with `role="menuitem"` per item and `role="menubar"` not used (it is a popup menu). Keyboard: Arrow keys + Enter/Space + Escape.
