# Card

A container with header, body, footer slots, variants, and hover effects.

## Usage

```tsx
import { Card } from 'morphui-react';

<Card variant="default" hoverable>
  <Card.Header>Title</Card.Header>
  <Card.Body>Content</Card.Body>
  <Card.Footer>Actions</Card.Footer>
</Card>;
```

## Accessibility

Renders `<div>` with no implicit role. Add `role="region"` + `aria-label` if the card represents a landmark. Hoverable cards get `role="button"` only if the entire card is clickable.
